Location, Location, Location

There are so many beautiful places in Asia that it's difficult to choose where to begin, so we've created a little shortlist.

It is not possible to choose accommodation without knowing dates and numbers, so we've put together a collection of Airbnbs that fit 10 - 16 people, separated by country. I hope that this will make it easier to calculate an estimated cost per guest, but should still be taken as an estimate only.

In this selection, we have considered a few key variables: price, activities, and amenities. Amenities in West Sumatra are notable fewer than in Thailand - but maybe that's the point? All four locations are near the beach which means activities include anything you'd love to do in crystal clear water. Some of these properties include food, transport and information about local activities where others do not. Getting to each location is going to involve at least one flight but some locations will require busses, boats or private transfers. Each listing should give you an idea about specialist transfers if necessary and you can also check the flight links below. Please take a good look at each property listed, as these are indicative of what we can expect in each location. Please select all the places you're happy to go!
